# Ottawa Painters React Native App

A lightweight cross-platform React Native app scaffold for iOS and Android built with Expo.

## Stack
- React Native
- Expo

## Local setup
1. Install dependencies
   - `npm install`
2. Start Metro
   - `npm start`
3. Open on:
   - iOS: scan with Expo Go or run `npm run ios` (requires Xcode + simulator)
   - Android: scan with Expo Go or run `npm run android` (requires Android Studio + emulator)

## Project files
- `App.js` app shell and bottom tab navigation
- `src/screens` main screens
  - `HomeScreen.js`
  - `ServicesScreen.js`
  - `QuoteScreen.js`
  - `ContactScreen.js`
- `src/theme.js` design tokens
